### 训练模型并获取用于评测的样本
- 训练DPO模型，统计训练过程的loss情况，和其他需要关注的训练指标
- 使用 DPO 模型与 BASE 模型分别在测试集/验证集上输出推理步骤和结论，记录输出结果到 data_dpo/out 下的 validate 和 test 文件夹，格式使用 json，再由大参数模型进行过程/结论/数据引用三维度比较。
用于评估以下指标。

### 效果评估（阶段三）
| 评估维度 | 具体指标 | 评估方法 | 预期目标 |
|----------|----------|----------|----------|
| **推理准确率** | 最终结论正确率 | DPO/BASE 模型对测试集生成结论，大参数模型三维度比较 | 相对基座提升 10%–15% |
| **推理过程质量（暂缓）** | 步骤正确率 | 大参数模型三维度比较（过程/结论/数据引用） | 平均步骤正确率提升 15% 以上 |
| **偏好对齐程度** | Preference Accuracy | 验证集上模型对 chosen/rejected 的区分准确率 | > 70% |
| **生成多样性** | 不同推理路径数量 | 同一问题多次生成，统计有效推理路径数 | 多样性保持或提升，不出现模式崩塌 |
| **策略稳定性** | 训练 loss 收敛曲线 | 监控 DPO loss 随训练步数变化 | 稳定下降，无明显震荡 |
| **参考偏离度** | 训练后模型与参考模型的 KL 散度 | 在验证集上估算 \(\text{KL}(\pi_\theta \| \pi_{\text{ref}})\) | 保持在 < 5.0 范围内 |
