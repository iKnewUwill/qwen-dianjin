# DPO 端到端三维度评估结果

> 评估对象：基座 Qwen3-8B（base）vs 两个 DPO 模型（`redo_step_mean`、`redo_fusion_weighted`）
> 评估数据：`dpo_test` 400 题；裁判：`qwen3.8-flash` 大模型（batch API）
> 评估维度：结论正确性、步骤正确性、数据引用准确性
> 结果文件：`src/data_dpo/test/batch_judge_{fusion_step,step}_result.jsonl`（各 400 条，全部成功解析）

---

## 1. 评估方法

- 对每道题，裁判模型**同一次调用**同时评判 base 与 DPO 两个模型的回答（配对盲评），输出 JSON：
  ```json
  {"base": {"conclusion": 1, "steps": [1,1,1], "data_accuracy": 1},
   "dpo":  {"conclusion": 1, "steps": [1,1,1], "data_accuracy": 1}}
  ```
- 评分口径：
  - **结论正确性**（conclusion）：1 正确 / 0.5 部分正确 / 0 错误
  - **步骤正确性**（steps）：逐步骤 1 正确 / 0 错误
  - **数据引用准确性**（data_accuracy）：1 准确 / 0.5 部分准确 / 0 不准确

---

## 2. 三维度统计结果

### 2.1 结论正确性（满分率 = 判「1」的比例）

| 模型 | 满分率 | 平均分 | 分布（1 / 0.5 / 0） |
|------|:---:|:---:|:---:|
| base（fusion 文件） | 49.75% | 0.736 | 199 / 191 / 10 |
| base（step 文件） | 46.00% | 0.724 | 184 / 211 / 5 |
| **dpo_step_mean** | **57.75%** | **0.776** | **231 / 159 / 10** |
| dpo_fusion_weighted | 53.50% | 0.756 | 214 / 177 / 9 |

### 2.2 步骤正确率（所有步骤判「1」的比例）

| 模型 | 步骤正确率 | 平均步骤数 |
|------|:---:|:---:|
| base（fusion 文件） | 62.33% | 3.05 |
| base（step 文件） | 62.98% | 3.05 |
| dpo_step_mean | 61.51% | 3.05 |
| dpo_fusion_weighted | 60.23% | 3.08 |

### 2.3 数据引用准确性（满分率 = 判「1」的比例）

| 模型 | 满分率 | 平均分 | 分布（1 / 0.5 / 0） |
|------|:---:|:---:|:---:|
| base（fusion 文件） | 34.00% | 0.652 | 136 / 250 / 14 |
| base（step 文件） | 35.00% | 0.659 | 140 / 247 / 13 |
| dpo_step_mean | 30.75% | 0.630 | 123 / 258 / 19 |
| dpo_fusion_weighted | 29.75% | 0.621 | 119 / 259 / 22 |

---

## 3. 配对对比（同一裁判调用内 dpo vs base）

| 对比 | 结论 | 步骤 | 数据引用 |
|------|:---:|:---:|:---:|
| **step_mean vs base** | **+10.6pp**（win 26.8% / tie 57.0% / loss 16.2%） | -1.6pp | -5.0pp |
| fusion_weighted vs base | +4.0pp（win 23.2% / tie 57.5% / loss 19.2%） | -2.3pp | -5.8pp |

> 裁判模型存在随机性：base 在两个文件中的结论满分率差 3.75pp（49.75% vs 46.00%），据此估计裁判噪声约 ±2~4pp（结论维度）、±1pp（步骤/数据引用维度）。

---

## 4. 评估结论

### 4.1 结论正确性显著提升，step_mean 最优

- **dpo_step_mean 结论满分率 57.75%**，较 base（46.00%）**提升 +11.75pp（相对 +25.5%）**，配对净胜 +10.6pp，远超裁判噪声，结果稳健。
- **dpo_fusion_weighted 结论满分率 53.50%**，较 base 提升 +3.75pp，方向一致但幅度与噪声相当，提升较弱。
- 结论维度与之前的**偏好准确率结论完全一致**：step_mean（99.25%）> fusion_weighted（98.88%），端到端结论正确率也复现了这一排序。

### 4.2 步骤正确性基本持平（略降，在噪声内）

- 两个 DPO 模型步骤正确率约 60~62%，与 base（62~63%）基本持平，配对净胜 -1.6pp ~ -2.3pp，在裁判噪声范围内。
- 说明 **DPO 偏好对齐并未提升步骤级推理质量**，其收益集中在「最终结论」而非「逐步推理过程」。

### 4.3 数据引用准确性略降

- 两个 DPO 模型数据引用满分率约 30~31%，较 base（34~35%）下降约 -4.25pp，配对净胜 -5.0pp ~ -5.8pp，略超噪声。
- 数据引用整体偏低（各模型约 60% 样本为「0.5 部分准确」），是三个维度中最薄弱的一环；DPO 训练未能改善、反而略有恶化。

---

## 5. 综合结论

1. **DPO 偏好对齐的端到端收益集中在「最终结论正确性」**：step_mean 提升 +11.75pp（显著）、fusion_weighted 提升 +3.75pp（较弱）。
2. **「步骤正确性」与「数据引用准确性」未通过 DPO 得到改善**，甚至略降——偏好信号（步骤级排序）优化了「结论」，却未传导到「过程细节」与「数据使用」。
3. **step_mean 模型是最终最优选择**：结论正确率最高（57.75%），与偏好准确率（99.25%）双指标一致，验证了「仅步骤平均排序」优于「加权融合」的结论。
4. 数据引用是三个维度的共性短板（各模型满分率仅 30% 左右），若需进一步优化，需针对性改进数据使用能力，而非仅靠 DPO 偏好对齐。

- base 在两个结果文件中因裁判随机采样评分略有差异，故对比采用**配对口径**（同一裁判调用内 base vs dpo），噪声最小。
